    The project code keeps everything editable; the WAV is playable audio. Everything is processed locally: nothing is uploaded and the microphone is never requested.

    How do I start?

    1. In section A, edit a drum pattern you like; click bass, chords or lead, then pick a pitch.

    2. Copy A to B and try shifting or varying it; everything can be undone.

    3. Arrange A and B into sections, set the repeats, play the whole song, then export.

    All four sounds are open. To practise basic rhythms, switch to the original Tour; the two modes and their saves never overwrite each other.

    Space plays/stops the current section; Esc stops or closes a dialog; arrow keys move inside the grid, Enter/Space changes strength. Editing or going to the background stops playback, and the next play uses the latest snapshot.

    Editable project

    Copy the PULSESONG1 project code to a friend, or download the project file. The three grids of an old PULSE2 save can be imported (old saves have no tempo, so 112 BPM is used). Everything is checked before replacing; if it fails, your song is kept.
